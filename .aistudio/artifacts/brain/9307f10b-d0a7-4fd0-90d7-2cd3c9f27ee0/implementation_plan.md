# SIMAX AI — Native Android Application Plan

بناء تطبيق أندرويد متكامل وفائق السلاسة يطابق بنسبة 100% موقع **SIMAX AI** بمظهره السايبربانك (الأحمر والأسود والنيون)، ونظام الذكاء الاصطناعي متعدد المستويات (عائلة نماذج S TURBO)، ومولد الصور المتقدم (Forge Animation)، والبحث الحي في الويب، وتحليل الملفات والصور، والدردشة الصوتية المباشرة، ونظام الحسابات ومفاتيح التفعيل التلقائية.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد القرارات التالية بناءً على إجاباتك:
> 1. **محرك الذكاء الاصطناعي**: مطابقة نظام الموقع مع الاعتماد على خوادم الذكاء الاصطناعي السريعة (Gemini 3.5 Flash عبر المفتاح المدمج، بالإضافة إلى مزودات S TURBO الاحتياطية ومحركات Groq وPollinations) لضمان استجابة فورية بدون انقطاع.
> 2. **الهوية البصرية**: النمط الأصلي للسايبربانك (أحمر ناري `#ff1f2f`، أسود عميق `#030303`، لمسات سماوي نيون `#14f0ff`، وتأثيرات الـ Glitch والشبكة وشريط الفحص وفلك النواة المشعة) مع دعم التبديل للوضع الفاتح (Solar Mode).
> 3. **الشعار والأيقونة الرسمية**: تم تجهيز بنية الشعار لتكون قابلة للاستبدال الفوري بالصورة الرسمية بمجرد إرسالها لاحقاً، مع استخدام الشعار السايبر المميز حالياً كأيقونة تكيفية (Adaptive Icon).
> 4. **سلاسة الأداء وتجربة المستخدم**: استخدام Jetpack Compose مع تقنيات الرسوميات المتقدمة، وتقديم ردود تدفقية سلسة (Streaming Text Animation)، واهتزازات لمسية خفيفة (Haptic Feedback)، وحفظ محلي فوري للمحادثات والذاكرة بدون أي بطء.

## 1. Overview & Core Concept

- **الهدف الأساسي**: نقل تجربة موقع SIMAX AI إلى تطبيق أندرويد أصلي فائق السرعة، يتيح للمستخدم التفاعل مع عائلة نماذج S TURBO:
  - **S TURBO FLASH**: النموذج فائق السرعة والردود المركزة (مجاني).
  - **S TURBO HIGH**: النموذج المتوازن ذو الأداء المعرفي الغني (مجاني).
  - **S TURBO MAX**: النموذج العميق ذو القدرات المتقدمة (محدود بـ 20 رسالة / 8 ساعات).
  - **S TURBO ULTRA MAX**: النموذج النخبوي الشامل لتاريخ الأرض والبشرية والدقة الفائقة (متاح بالترقية ومفاتيح الترخيص).
- **الميزات التفاعلية**:
  - محادثة نصية حية مع تأثير الطباعة التدريجي.
  - صياغة وتوليد الصور (Prompt Forge) مع حلقات مدارية متحركة وتأثيرات أشعة ليزرية ومراحل التصيير.
  - البحث الفوري في الويب (Live Web Grounding) لجلب أحدث الحقائق والأخبار.
  - تحليل المستندات والصور (Multimodal Vision).
  - وضع التحدث الصوتي الحي (Voice Mode) بأورب نيون نابض وصوت رجالي عميق.
  - نظام الذاكرة الذكية (User Memory) لتذكر الحقائق والاسم والاهتمامات.
  - إدارة الجلسات والمحادثات السابقة (Sidebar Drawer).
  - نافذة الإعدادات الكاملة (المظهر، أسلوب الردود، الاشتراك وتفعيل المفاتيح، تصدير البيانات، وحول SIMAX TEAM).

## 2. User Experience & Visual Design

### التسلسل البصري والألوان
- **Void Black**: `#030303` للخلفيات الأساسية لتقليل استهلاك البطارية على شاشات AMOLED.
- **Panel Dark**: `#080808` و `#0e0e0e` لبطاقات الرسائل والألواح الجانبية.
- **Blood Red**: `#ff1f2f` و `#ff4d4d` للأزرار التفاعلية ومؤشرات الوهج.
- **Ember Coral**: `#ff6b6b` لبطاقات الترقية والميزات الممتازة.
- **Signal Cyan**: `#14f0ff` لتأثيرات الجليتش والوميض الرقمي.
- **Line Borders**: `#1d1d1d` لحدود دقيقة أنيقة.

### شاشات وتدفقات التطبيق (Flows)
1. **الشاشة الرئيسية (Chat View)**:
   - شريط علوي أنيق يحتوي على زر فتح القائمة الجانبية، اسم وعلامة SIMAX AI، قائمة اختيار النماذج (Model Selector Dropdown)، زر الترقية (Upgrade)، ومبدل الوضع الليلي/الشمسي، وزر الصوت والإعدادات.
   - منطقة الرسائل مع دعم الماركداون والشيفرات البرمجية مع زر النسخ وتحديد رقم الأسطر.
   - شريط إدخال عصري بيضاوي يحتوي على زر إرفاق الملفات/الصور، حقل النص المرن، زر الإدخال الصوتي، وزر الإرسال والإيقاف.
2. **شريط الجلسات الجانبي (Sessions Drawer)**:
   - زر "+ New Chat" وموجز زمني للمحادثات السابقة مع إمكانية حذف أي محادثة وتوقيع "by SIMAX TEAM".
3. **نافذة الترقية والاشتراك (Upgrade & License Key Modal)**:
   - التبديل بين الخطة الشهرية والسنوية، واستخراج مفتاح الترخيص الفريد وتفعيله بنقرة واحدة لفتح نموذج ULTRA MAX.
4. **نافذة المحادثة الصوتية (Live Voice Mode)**:
   - أورب نيون كبير يتغير حاله وتأثير وهجه بين (جاهز Idle، يستمع Listening، يفكر Thinking، يتحدث Speaking) مع تفاعل لمسي.
5. **نافذة الإعدادات (Settings Dialog)**:
   - 5 أقسام مطابقة للموقع: General (السمة واللغة)، Responses (أسلوب النماذج)، Subscription (إدارة الترقية)، Data & Privacy (تصدير المحادثات ومسح الذاكرة)، وAbout (معلومات SIMAX TEAM).

## 4. الخطوات التنفيذية (Plan Execution Roadmap)

- **المرحلة 1: البنية الأساسية وضبط الحزم والأذونات**:
  - تفعيل سرية `GEMINI_API_KEY` ومطابقة المكتبات ومحددات الشبكة والصوت في `AndroidManifest.xml` و `build.gradle.kts`.
  - تجهيز أيقونة التطبيق التكيفية (Adaptive Launcher Icon) بألوان SIMAX السايبربانك.
- **المرحلة 2: محرك الذكاء الاصطناعي وشبكة البيانات**:
  - برمجة `SimaxAiRepository` المتوافق مع عائلة نماذج S TURBO وتدفق الردود (Streaming).
  - دمج خدمة البحث المباشر (DuckDuckGo + Wikipedia) لتحسين دقة الإجابات مع تفعيل خاصية الذاكرة الذكية.
  - دمج محرك توليد الصور الفوري وتأثير التحميل الفني (Image Forge).
- **المرحلة 3: واجهات المستخدم Jetpack Compose**:
  - صياغة نظام الألوان والتصميم النيون في `Theme.kt` و `Color.kt`.
  - بناء مكونات الرسائل وعارض الشيفرات البرمجية وأزرار النسخ والتوليد.
  - بناء الدردشة الصوتية المباشرة مع محرك التعرف الصوتي والنطق الصوتي.
  - بناء القائمة الجانبية ونوافذ الإعدادات والترقية بمفاتيح التراخيص.
- **المرحلة 4: فحص البناء والتحقق النهائي**:
  - فحص التطبيق وتجميعه عبر `compile_applet` وضمان خلوه من أي أخطاء أو بطء.
